## 1. 版本与兼容性

本版本新增此前不存在的真实阶段 A 读取能力，并冻结财报修订、股息分类和回购
日期的 UNKNOWN 边界。

- v1.0.0/v1.1.0 的合成 fixture 结果保持可比；
- v1.1.0 的授权范围不包含真实数据研究。任何基于 v1.1.0 产生的真实数据研究、
  选股或回测产物均属于未经授权的审计产物，v1.2.0 不予承认，不得作为迁移、
  业绩引用或策略决策依据；若需保留，必须在后续完整链路 ready 后按新 manifest
  重新运行；

- 不得用 v1.2.0 Reader 重新解释旧 manifest；

## 2. 拟新增的 PIT 条文

在“PIT 与运行元数据”中追加：

1. 日频市场 `as_of: date` 表示该日收盘后。该日 RAW 收盘价可用于生成信号，
   但组合模拟最早只能在下一可交易时点成交，禁止用产生信号的同一收盘价成交。
2. **研究 `as_of` 覆盖**：所有信号生成和历史价格/因子/利率查询必须位于该域
   快照配置的
   `config.start_date <= requested_date <= config.end_date`。越界抛出明确的
   coverage 错误，不得返回部分区间、空集合冒充完整结果或最近旧值。
3. **成交日推导缓冲**：日历同步可保存 `(end_date, end_date + 10 天]`。采集层
   只可用它为 `obs_date <= end_date` 的最后观测推导 `available_at`；读取层只可
   用它回答 `next_trading_day(end_date)`，以安排 `end_date` 收盘信号后的首个
   成交日。缓冲中的日期可以作为未来成交安排结果，但不得作为研究 `as_of`，
   不得参与任何信号生成、历史价格、因子、利率或证券池查询。这是成交日推导，
   不是研究覆盖区间扩张。
4. 法定原始财报及更正公告各自按保守 `available_at` 进入 PIT。免费源
   `latest_restated_only` 只可从 `first_observed_at` 起使用。
5. `observation_revision_sequence` 仅描述本地开始采集后的观察顺序，不得冒充
   `provider_revision_sequence`。首次观察前无法恢复的版本为 UNKNOWN，禁止用
   当前值回填历史。
6. 长历史财报回测若要求完整 PIT，必须取得有序供应商修订源，或逐份解析法定
   原文和更正公告；否则该期间财务输入为 UNKNOWN。

## 3. 拟新增的股息条文

1. 明确属于年度利润分配的普通股基础现金股息，且法定文件未标注“特别、
   额外、一次性、清算、资本返还”等性质时，`is_ordinary=TRUE`。
2. 明确的特别、额外或一次性部分为 FALSE。混合方案可可靠拆分金额时拆为多个
   事件；不能拆分时整项为 UNKNOWN。
3. 中期股息仅在法定文件明确属于常规分配政策时为 TRUE，否则 UNKNOWN。
4. 实施公告中的预定支付日不证明支付完成。明确完成公告或后续法定定期报告
   才能从自身 `available_at` 起令 `is_paid=TRUE`；更正或取消建立新修订，禁止
   回填旧时点。
5. 未证明查询窗口事件覆盖完整时，聚合 `D=UNKNOWN`，即使已找到的单项事件
   均完整也不得把未发现事件当作不存在。

## 4. 拟新增的回购条文

1. 累计进度差分只形成 `[interval_start, interval_end]` 区间审计证据，不得把
   区间首日、末日、公告日或 `available_at` 伪装成 `executed_on`。
2. 主路径 `B_actual_365d`、最近完整自然年金额和持续性判断必须使用逐日或逐笔
   实际执行日期；缺少精确日期时为 UNKNOWN。
3. 区间金额可单独报告上下界，但不得代入 `GG`、价阶或回购持续性。
4. 本版本不采用“统一归到区间末日”等近似法。未来若采用，必须升级规则版本
   并增加窗口边界黄金算例。

## 6. 阶段 A 强类型输出

### 6.1 `RawPriceBar`

- `security_id: str`，必须为 `sh.600000` / `sz.000001` 规范形式；
- `trade_date: date`；
- `open/high/low/close: Decimal`，必须有限且非负；零值只能保留为来源占位证据，
  不得作为正的估值价格 `P`；
- `volume/amount: Decimal | None`，非空时有限且非负；
- `paused: bool | None`；null 为 UNKNOWN，不得当作 FALSE；
- `evidence_ref: str | None`、`source_row_hash: str | None`；完整 bar 两者必须非空，
  但来源缺失值必须原样保留为 None，并生成 `EVIDENCE_MISSING`，不得为了通过
  类型校验伪造证据；
- 只接受 `adjust_type=RAW`。

`price_bars` 返回不可变 `PriceBarSeries`，字段固定为：

- `bars: tuple[RawPriceBar, ...]`；
- `coverage_issues: tuple[CoverageIssue, ...]`；
- `quality_flags: tuple[str, ...]`；
- `coverage_complete: bool`，派生为 `not coverage_issues`，调用方不得单独赋值。

bar 按 `(security_id, trade_date)` 唯一并按日期升序，满足
`start <= trade_date <= min(end, as_of)`。

- 请求边界超出快照配置区间属于调用错误，抛 coverage 异常；
- 请求在快照区间内出现下述任一问题时返回 `coverage_complete=FALSE`，但下游
  必须按问题类型处理，不能一刀切；
- 单日估值 `P` 只接受 `as_of` 当日正的可交易 RAW close；非交易日、停牌、
  零占位或缺 bar 均为 UNKNOWN，不自动沿用前收盘。

`CoverageIssue` 为不可变值对象，字段固定为：

- `issue_type: CoverageIssueType`；
- `security_id: str`；
- `date_range: tuple[date, date]`，闭区间且起点不得晚于终点；单日问题两端相同；
- `evidence_ref: str | None`，没有可定位证据时必须为 None，不能伪造。

所有 `date_range` 都限制在有效查询区间 `[start, min(end, as_of)]` 内。
`SECURITY_NOT_COVERED` 覆盖整个有效查询区间；其他类型按具有相同
`issue_type` 和 `evidence_ref` 的最大连续受影响交易日区间合并，并按
`(security_id, date_range 起点, date_range 终点, issue_type)` 稳定排序。

`CoverageIssueType` 与下游语义固定为：

| issue_type | 含义 | 下游处理 |
|---|---|---|
| `SECURITY_NOT_COVERED` | 证券列入 snapshot `missing_security_ids` 或完全不在行情覆盖中 | 该证券的阶段 A 行情能力为 `NOT_SUPPORTED`；这不是规则不适用，禁止映射为 `NOT_APPLICABLE` |
| `MISSING_BAR` | 证券在覆盖集合内，但应有交易日缺 bar | 只使受影响日期输入 UNKNOWN；其他有证据日期仍可用，要求完整窗口的规则为 UNKNOWN/NEEDS_REVIEW |
| `PAUSE_STATUS_UNKNOWN` | bar 存在但 `paused=null` | 数值价格可用于不要求可交易性的描述；流动性、可交易性、成交模拟以及要求“可交易收盘价”的 `P` 为 UNKNOWN |
| `EVIDENCE_MISSING` | bar 数值存在但 `evidence_ref` 或 `source_row_hash` 缺失 | 数值仍可用于不要求可追溯性的计算或诊断，但不得形成可发布的标准通过结论；证据依赖规则为 NEEDS_REVIEW |

若 `evidence_ref` 与 `source_row_hash` 仅缺一个，issue 的 `evidence_ref` 使用仍存在
的可定位引用；两者均缺时为 None。`CoverageIssue.evidence_ref` 只定位问题，不得
用来补写 `RawPriceBar` 缺失的证据字段。

缺 bar 不能解释为价格为零、明确停牌、证券不存在或 NOT_APPLICABLE。

### 6.2 `AdjustmentFactorObservation`

- `security_id: str`、`ex_date: date`、`available_at: date`；
- `cumulative_factor: Decimal`，有限且严格为正；
- `factor_source/evidence_ref/source_row_hash: str`，必须非空。

先固定可见集合 `V(as_of) = {observation | available_at <= as_of}`。StockDB
字段是供应商已经计算好的**累积因子水平**，不是待相乘的单次事件乘数。对任意
`d <= as_of`：

- 在 `V(as_of)` 中选择 `ex_date <= d` 且 `ex_date` 最大的观察；同一 `ex_date`
  有修订时再取 `available_at` 最大的一条，`F(d)` 等于其 `cumulative_factor`；
- 同一 `(security_id, ex_date, available_at)` 若出现相互冲突的因子值，属于
  数据完整性硬错误，不得任意选择；
- 若不存在这样的观察，`F(d)=1`；
- `F(as_of)` 按完全相同的方法在同一 `V(as_of)` 中求得；
- 禁止将历次 `cumulative_factor` 再次连乘；
- 因子是否可见统一以查询时点 `as_of` 为截止，而不是分别以历史日期 `d` 的
  当时可见集合计算，从而让整条序列处于同一 as-of 因子版本且不读取
  `available_at > as_of` 的未来观察。

研究前复权公式冻结为：

```text
AdjustedPrice(d, as_of) = RawPrice(d) × F(d) / F(as_of)
```

该公式必须复用或等价于现有 `adjusted_close_to_as_of`，并通过 FX-001 与真实
浦发银行 2022–2026 除权连续性 fixture。交易模拟仍只使用 RAW 价格并独立处理
公司行为。

### 6.3 `RateObservation`

- 唯一 series 标识：`CN_GOVT_10Y_YIELD_PCT`；未知标识抛参数错误，不提供别名；
- `obs_date/available_at: date`；
- `value: NonNegativePct`，`1.7` 表示 `1.7%`；
- `curve_id="ycqx"`、`curve_name="中债国债收益率曲线"`、`tenor="10Y"`；
- `evidence_ref/source_row_hash: str`，必须非空。

选择最新的 `available_at <= as_of` 记录。陈旧度定义为开区间
`(available_at, as_of)` 内的交易日数量，允许值固定为 `0`。若该开区间内存在
至少 1 个交易日，说明期间本应出现更新发布日而当前记录已陈旧，返回
None/UNKNOWN，不继续向前寻找更旧值。周末和长假不产生交易日，因此不增加
陈旧度：周五 `available_at` 到下周一的开区间只有周末，计数为 0；周四到
下周一的开区间包含周五，计数为 1；春节前最后交易日到节后首个交易日之间若
无交易日仍为 0。2005 年源缺口返回 None/UNKNOWN。实现不得将任一端点计入，
也不得用日历日差替代交易日计数。

### 6.4 `TradingCalendarReader`

- `calendar_day(exchange, day) -> bool | None`：TRUE 为交易日，FALSE 为明确休市，
  None 为未覆盖；
- `previous_trading_day(exchange, day) -> date | None`：严格早于 `day`；
- `next_trading_day(exchange, day) -> date | None`：严格晚于 `day`；
- 范围中存在缺日时不得返回部分推导；
- 当前只接受 `exchange="cn"`；未知交易所抛参数错误；
- `calendar_day`、`previous_trading_day` 和普通 `next_trading_day` 的研究日期
  均受 `start_date..end_date` 约束；
- 唯一缓冲例外是 `next_trading_day(end_date)`：可读取
  `(end_date, end_date + 10 天]` 并返回 `end_date` 收盘信号后的首个成交日；
- 该返回值是成交安排日期，不是新的研究 `as_of`。缓冲中的日期不得用于信号
  生成、证券池、价格、因子或利率读取，也不得递归调用
  `next_trading_day(buffer_date)` 继续向后扩张。
