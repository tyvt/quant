## 1. 版本、范围与授权

规则版本升级为 `v1.3.0`。这是新增完整 Profile 和组合模块的 MINOR 版本，
不重新解释 v1.0.0–v1.2.0 的历史运行。

本版本只支持：

- 沪深主板人民币普通股；
- 通用 FCF 模型适用的非金融、非房地产开发企业；
- 多头、无杠杆、最多 20 只、月度调仓的参考策略；
- 以完整 PIT 数据驱动的研究与日频组合模拟。

银行、保险、证券及其他金融企业、房地产开发企业和无法可靠分类的企业返回
`NOT_SUPPORTED`，不得套用本 Profile。其他板块及其他策略风格不在本版本范围。

本次批准授权编写纯领域、策略和回测实现及合成 fixture。真实研究/回测仍须同时
满足 §11 的所有生产数据门槛；任一门槛未满足时，只能输出数据验收或
`NEEDS_REVIEW`，不得发布选股、净值或绩效。

## 2. 通用财务归属与标准输入

所有财务流量优先使用同一币种、同一会计范围的合并报表；存量使用期末值，流量
使用完整年度或严格可比 TTM。合并/母公司范围混用、币种不一致、期间不连续或
来源修订链不完整时为 `UNKNOWN`。

### 2.1 科目归属

- `E = 归属于母公司所有者权益`；必须大于零。`E_latest` 是截至 `as_of` 已可见
  的最近报表期末值，可来自年报或中期报告；`Y0` 是截至 `as_of` 已有完整、
  可追溯年报可见的最近一个完整财年末，不是事后所知的最新财年；
- 五个年度 ROE 固定使用 `Y0` 至 `Y0-4` 的归母净利润，以及 `Y0` 至 `Y0-5`
  六个连续财年末的 `E`。每一观察都必须 `available_at <= as_of`。任一年度缺失、
  不可追溯、范围不一致或未来才可见时，`premise.roe_5y=UNKNOWN`；不得跳过缺年，
  也不得用 `Y0-6` 或更早权益替代 `Y0-5`；
- `N = 少数股东权益`；只有同期总权益可核实等于 `E` 时，缺失才可解释为零；
- `C` 的两个原始输入各自保留已知/未知状态，计算严格分为：
  - 货币资金已知、受限金额明确已知为 `0`：`C=货币资金`；
  - 货币资金已知、受限金额明确已知为正数：`C=货币资金-受限金额`；
  - 货币资金已知、受限金额未知：`C=UNKNOWN`，不得当作零或直接使用货币资金；
  - 货币资金未知：`C=UNKNOWN`，无论受限金额状态为何；
  - 受限金额为负或大于已知货币资金属于数据完整性错误，硬失败而非 UNKNOWN。
    “明确为零”必须有来源值或证明不存在受限项目的证据；缺字段不是零；
- `A` 只包含一年内可变现、明确属于金融资产且未计入 `C` 的项目。交易性金融
  资产、债权投资、其他债权投资和一年内到期的金融资产按附注明细纳入；
  `OTHER_CURRENT_ASSET` 不因名称含“流动”而自动纳入；
- `B_debt` 包含短期借款、明确属于有息债务的一年内到期负债、应付短期债券、
  长期借款、应付债券和租赁负债。无法从混合科目拆出有息部分时为 `UNKNOWN`；
- `OCF = 经营活动产生的现金流量净额`；
- `Capex = 购建固定资产、无形资产和其他长期资产支付的现金`，以正支出表达；
- `Lease_cash_not_already_deducted` 只计未已包含在 OCF 或 Capex 中的现金租赁
  支出；无法排除重复扣减时为 `UNKNOWN`；
- `S` 使用 `as_of` 当日收盘后可见、与普通股经济权益一致的总股数；
  `MV=P×S`。当前证券主表没有历史股本，因此批准本条不等于股本数据 ready。

来源字段到上述规范项的映射必须版本化并逐项保留证据。任何未列明原始字段不得
通过模糊名称自动并入。

### 2.2 FCF 路径

通用 Profile 的标准绝对估值统一使用保守口径：

```text
alpha_y = E_y / (E_y + max(N_y, 0))
FCF_y = (OCF_y - Capex_y - Lease_cash_not_already_deducted_y) * alpha_y
F1..F5 = 最新至最早五个完整年度的 FCF_y
```

`FCF_ordinary` 继续作为诊断项报告，但不得替代标准 `F1..F5`。负值保留，缺年
不得跳过或用更早年份补位。

`L` 优先采用最新严格可比 TTM 的保守 FCF：

```text
L = FCF_FY_previous + FCF_YTD_current - FCF_YTD_previous_comparable
```

若最新可见期恰为完整年度，则 `L` 为该年度 FCF；`L_prev` 使用向前平移一年的
同口径值。TTM 三段的报表范围、币种、累计口径或期间不可比时，`L=UNKNOWN`。

穿透回报的 `O` 独立定义为截至 `as_of` 最新完整年度的保守归母 FCF：

```text
O = (OCF - Capex - Lease_cash_not_already_deducted) * alpha
```

`O` 不使用 `F_norm`、`F0`、预测值或季度机械年化替代；原始负值保留，由现有
共享容量公式执行 `max(O, 0)`。

## 3. `GENERAL_FCF` 企业前提

### 3.1 硬门

以下规则全部为 `HARD_GATE`，任一未知按既有优先级产生 `NEEDS_REVIEW`：

1. `premise.profile_supported`：点时行业分类明确为通用非金融、非房地产开发；
2. `premise.statement_integrity`：五个完整年度及 TTM 所需期间均为同范围、同币种、
   可追溯版本；最新年报审计意见为无保留意见，且没有持续经营重大不确定性；
3. `premise.positive_equity`：最新 `E > 0`；
4. `premise.roe_5y`：按 §2.1 的 `Y0..Y0-4` 计算五年 ROE，中位数至少 `10%`。
   年度 ROE 使用 `parent_net_profit / average(E_begin, E_end) × 100`；六个连续
   年末权益中任一不可用即为 UNKNOWN；
5. `premise.fcf_consistency`：五个标准保守 FCF 中至少四个严格大于零；
6. `premise.leverage`：`net_debt=max(0, B_debt-C-A)`；若 `F_norm>0`，要求
   `net_debt/F_norm <= 3`；若 `F_norm<=0` 则失败，必要输入未知则未知。

风险警示、立案调查或重大违法状态不伪装成企业财务前提；它们在证券池规则中
独立处理并保留各自点时证据。

### 3.2 质量评分

通过全部硬门后计算 `quality_score`，范围 `[0,100]`，四个分项均为 `SCORE`：

```text
roe_score = clamp((median_roe_5y - 10) / 10, 0, 1) * 100
fcf_stability_score = positive_fcf_years / 5 * 100
cash_conversion = sum(OCF_y * alpha_y) / sum(parent_net_profit_y), y=1..5
cash_conversion_score = clamp(cash_conversion / 1.2, 0, 1) * 100
balance_score = 100,                                      if net_debt = 0
                clamp(1 - net_debt / (3 * F_norm), 0, 1) * 100, otherwise

quality_score = 0.35 * roe_score
              + 0.25 * fcf_stability_score
              + 0.25 * cash_conversion_score
              + 0.15 * balance_score
```

配置构造时必须校验四个权重均为非负有限 `Decimal`、键集合恰好匹配四个分项，
且精确合计 `1.00`；不使用浮点容差，也不接受多余或缺失权重。校验失败属于配置
错误并硬失败。

`sum(parent_net_profit_y) <= 0` 时现金转换分项为 `UNKNOWN`。任何适用分项未知时，
`quality_score=None`，`score_coverage` 只等于已知分项原始权重之和；不得重分配
权重或把已知分项重新归一化。可以另报加权已知贡献
`reference_raw_score`，但不得进入 Tier 或参与官方排序。质量分不再设置额外候选
阈值；它只在已通过硬门和 D/E 候选条件的证券之间排序。

### 3.3 规则性质与未知值聚合

本版本补齐此前正文与测试之间未写清的边界：

- `HARD_GATE=UNKNOWN/NEEDS_REVIEW`：顶层为 `NEEDS_REVIEW`；
- `SCORE=UNKNOWN/NEEDS_REVIEW`：该项仍计入适用权重分母，使
  `score_coverage<1`，顶层为 `NEEDS_REVIEW`；
- `EVIDENCE=UNKNOWN/NEEDS_REVIEW`：证据链不足，阻断可发布的标准结论，顶层
  为 `NEEDS_REVIEW`；
- `INFORMATION=UNKNOWN/NEEDS_REVIEW`：只附注，不改变已由完整硬门、评分和
  证据得出的顶层结论；
- 任一阻断型未知仍优先于 `HARD_GATE=FAIL`，避免在关键输入未知时声称已证明
  淘汰；纯 `INFORMATION` 未知不参与该优先级。

这保留现有 `EVIDENCE=UNKNOWN` 的 fail-closed 黄金行为，同时修正当前实现把纯
`INFORMATION=UNKNOWN` 也一律升级为 `NEEDS_REVIEW` 的过宽处理。

## 4. 行情位置 Profile

`market.position` 使用与绝对估值相同 `as_of`、同一因子可见集和
`ADJUSTED_TO_AS_OF` 收盘价：

- 回看截至 `as_of` 的最近 `756` 个交易日；
- 至少需要 `504` 个有证据的正收盘价；不前向填充停牌或缺失日；
- 查询区间内存在无法由明确停牌解释的 `MISSING_BAR`、因子冲突或证据缺失时，
  标准结果为 `UNKNOWN/NEEDS_REVIEW`；
- `position_pct` 使用当前价格在样本价格中的 mid-rank 百分位：

```text
position_pct = (count(price < P) + 0.5 * count(price = P)) / n * 100
drawdown_from_high_pct = (P / max(price) - 1) * 100
market_position_score = 100 - position_pct
```

全部历史价格相等时 `position_pct=50`。报告标签固定为：`[0,20] LOW`、
`(20,40] LOWER_MID`、`(40,60] MID`、`(60,80] UPPER_MID`、`(80,100] HIGH`。
标签仅解释，不单独淘汰证券；`market_position_score` 进入 §6 排序。
该结果未知时不改变单证券 D/E 候选事实，但该证券不能进入官方横截面排序。

## 5. 点时证券池与信号

每个信号日按以下顺序形成证券池：

1. `security_ids_as_of(as_of)` 中仍处于主板有效区间的沪深 A 股；
2. 上市已满 `504` 个交易日；
3. 点时行业为 `GENERAL_FCF` 支持范围；
4. 当日未处于 ST、*ST、退市整理、暂停上市或已公告终止上市状态；
5. `MV >= CNY 5,000,000,000`；
6. 最近 60 个交易日中至少 50 个有证据、可交易的 amount，且其中位数
   `>= CNY 20,000,000`；
7. 阶段 A 覆盖问题、股本、行业或状态未知时，该证券为 `NEEDS_REVIEW`，不得
   伪装成“不在池中”。

信号日为每个自然月最后一个中国交易日，`as_of` 表示收盘后。D/E 公式和
`pipeline.decision` 保持现状：全部硬门已知且通过、`Coverage(6)>=1`、
`GG>=II`、所有适用评分完整时才是 `CANDIDATE`。

官方候选表要求结构证券池中的每只证券都有可审计终态
`CANDIDATE/REJECTED/NOT_SUPPORTED`；存在 `NEEDS_REVIEW` 时可以生成诊断报告，
但该月不得生成官方 Top-N 或用于可发布回测。这一严格门槛用于避免把数据缺口
当作自然淘汰而产生选择偏差。

诊断报告的边界固定为：

- 可以包含每只证券的硬门、评分、证据状态、缺失字段、`NEEDS_REVIEW` 原因和
  数据质量旗标；
- 不得包含横截面分位数、`composite_score`、任何排序、Top-N、候选推荐顺序、
  目标权重、订单计划、持仓或净值；
- 输出文件名、schema 和报告标题必须带 `diagnostic_only=true` 与
  `official_selection=false`，不得使用“非官方排名”等近似措辞绕过边界。

`CNY 5,000,000,000` 与 `CNY 20,000,000` 是本版本确认采用的预先冻结基线，
不是制度事实，也不是回测调优结果。标准初始资金 1000 万元、单仓上限 5% 时，
单仓目标最多 50 万元；相对 2000 万元成交额为 2.5%。该筛选只决定进入详细
研究的最低流动性，实际成交仍受 §8.1 更严格的逐日完整参与率限制。任何阈值
修改都必须升级规则版本，不能按回测结果静默调整。

## 6. 排序与目标组合

只对同一信号日的 `CANDIDATE` 排序。横截面百分位均使用 mid-rank，值越高越好；
对候选值 `x` 精确定义为
`(count(value < x) + 0.5 * count(value = x)) / n * 100`；只有一个候选时为 50。

```text
coverage_rank = percentile_rank(Coverage(6)) * 100
gg_margin_rank = percentile_rank(GG - II) * 100

composite_score = 0.30 * quality_score
                + 0.30 * coverage_rank
                + 0.30 * gg_margin_rank
                + 0.10 * market_position_score
```

按 `composite_score` 降序、`security_id` 升序稳定排序，取前 20 名。无行业内二次
排名，也不因候选不足而放宽规则。

目标权重固定为：

```text
selected_count = min(candidate_count, 20)
target_weight_i = min(5%, 1 / selected_count), selected_count > 0
```

由于最多 20 只，20 只时各 5%；少于 20 只时每只仍不超过 5%，剩余持有现金。
不加杠杆、不做空、不把现金自动分摊给剩余证券。标准基准运行初始资金为
`CNY 10,000,000`；其他初始资金属于不同配置哈希。
候选数为零时目标组合是 100% 现金，已有持仓按 §7 生成退出订单。

## 7. 调仓与卖出

- 每月信号后首个可交易日按目标权重调仓；禁止信号收盘价成交；
- 每月完整重算。现有持仓不再是候选或不在 Top 20 时，目标权重为零；
- 不设置排名缓冲、止盈、止损或盘中择时，避免把未验证规则偷偷加入基线；
- 同一成交时点先处理卖单，卖出所得现金可用于当日后续买单；
- 买入数量向下取整到 100 股；卖出可一次性处理不足 100 股的剩余零股；
- 目标差额不足一手时不下单，残余现金保留；
- 目标持仓金额固定为信号日收盘净值乘目标权重；目标股数用信号日 RAW 收盘价
  向下取整，不能用次日已实现开盘价反算后假装信号日已知；
- 次日跳空和费用导致现金不足时，所有买单先按同一比例缩减，再向下取整到整手；
  剩余现金按 `composite_score` 降序、`security_id` 升序逐手补配，且不得突破
  原目标股数、参与率或现金余额；未执行差额不因价格变化自动扩大；
- 快照 `end_date` 的信号只能由日历缓冲安排下一成交日；若成交日行情不在显式
  市场快照覆盖内，订单保持 `PENDING_OUT_OF_COVERAGE`，不得产生虚构成交。

## 8. 回测成交与成本

### 8.1 成交

- 成交基准价为订单可执行日的 RAW 开盘价；买入价乘
  `(1 + 10 bps)`，卖出价乘 `(1 - 10 bps)`；
- 日参与率上限为执行日严格之前的 20 个中国交易日平均成交额的 `5%`。20 个
  日期必须逐日完整：每一天都须有可追溯 amount；明确停牌且有证据的零成交额
  以 `0` 计入，分母始终为 20，不跳过、不改用更早交易日。任一日缺 bar、amount
  未知、证据不足、交易日历缺口或尚无 20 日历史时，参与率为 UNKNOWN；该执行日
  不成交并记录 `PARTICIPATION_RATE_UNKNOWN`，待执行订单仍按五日上限继续计时；
- §5 的“60 日中至少 50 个可交易日”是证券池最低流动性筛选，§8.1 的完整 20 日
  是实际成交能力上限；两者用途不同，前者通过不能替代后者完整；
- 未成交数量最多顺延 5 个交易日，期间每天重新检查交易能力和参与率；到期取消；
- 必须读取点时 `can_buy/can_sell`、停牌和涨跌停/无涨跌停状态。不得仅凭 OHLC、
  前收盘和证券名称猜测能否成交；状态未知时当日不成交并标记质量问题；
- 买入股份自下一交易日起可卖，逐成交批次执行 T+1；
- 同日卖出所得现金可用于买入，但未交收股份不可卖出。

### 8.2 成本

标准政策参数如下，全部进入配置哈希：

| 项目 | 标准参数 | 方向 |
|---|---:|---|
| 券商净佣金 | `3 bps`，每笔最低 `CNY 5` | 双边 |
| 模型滑点 | `10 bps` | 双边，进入成交价 |
| 交易所经手费 | 按成交日有效官方费率表 | 双边 |
| 过户费 | 按成交日有效中国结算费率表 | 双边 |
| 证券交易印花税 | 按成交日有效税率表 | 卖出单边 |

佣金定义为不含经手费、过户费和印花税的净佣金，避免重复计费。任何费率必须按
生效日期版本化；禁止用 2026 年费率回填更早历史。若某日费率表没有覆盖，成交
成本为 `UNKNOWN`，对应运行不可发布。

### 8.3 公司行为与异常退出

- 现金股息只在核实的实际支付日计入现金；基线报告为“交易成本后、股息税前”，
  不模拟个人持有期限差异税；
- 送股、转增、拆并股在除权日开盘前调整持仓股数和单位成本，资产总额不凭空
  改变；
- 配股、权证、换股、要约收购及无法定价的重组在未有专用规则时使持仓路径
  `NEEDS_REVIEW`；不得默认为不参与或按零价值处理；
- 持仓证券停牌或跌停不能成交时继续持有并按有证据的收盘价估值；估值也未知时
  净值标记不完整。若有独立、点时明确的停牌证据，可仅为组合记账沿用停牌前
  最后一个有证据的 RAW 收盘价并记录陈旧天数；该沿用值不得成为估值输入 `P`、
  信号价格、流动性 bar 或成交价；
- 退市前按相同卖出规则尝试执行。若最终退出现金流或剩余权利未知，不得用最后
  收盘价、零或事后恢复价格替代；整段可发布绩效被阻断。

现金余额不计利息。融资、融券、申购新股和盘后固定价格交易不在本版本范围。

## 9. 基准与绩效

主基准固定为中证全指全收益指数 `H00985`。基准日值必须来自显式、不可变、按
日期完整的快照；缺日不前向填充。策略和基准在共同可评估交易日对齐。

基准候选来源固定为中证指数有限公司官网官方 JSON 接口：

```text
source_id = csindex_official_index_perf_v1
endpoint = https://www.csindex.com.cn/csindex-home/perf/index-perf
params = indexCode=H00985, startDate=YYYYMMDD, endDate=YYYYMMDD
```

生产适配器直接请求官方接口，不以 AKShare 或其他第三方封装作为数据权威或运行
依赖。原始 JSON 响应须原样保存并哈希；规范行至少保留交易日、指数代码、中文/
英文全称、收盘点位、来源响应哈希、抓取时点和证据引用，只接受代码 `H00985`
及严格为正的有限 close。接口失败、身份漂移或区间缺口时硬失败，不自动切换
第三方来源。

2026-09-29 的只读可行性探针返回 2004-12-31 至 2026-09-24 共 5,281 行，收盘
空值 0、错误代码 0、重复日期 0。该探针只证明候选来源可读；在适配器、schema、
日历对账、不可变发布、内容哈希、撤销和真实 fixture 完成前，基准域仍为
`not_ready`。

至少报告：

- 期初/期末净值、累计收益、CAGR；
- 日收益年化波动率（固定 `252`）、最大回撤及起止日；
- 以当日可见中债 10Y 为无风险利率的 Sharpe；
- 相对基准的超额 CAGR、年化跟踪误差和信息比率；
- 月度胜率、年度收益表、换手率、持仓数、现金比例；
- 佣金、滑点、经手费、过户费和印花税分别累计；
- 未成交、部分成交、停牌、限价阻断和数据不完整次数。

指标公式冻结为：

```text
daily_return_t = NAV_t / NAV_(t-1) - 1
calendar_years = (end_date - start_date).days / 365.2425
CAGR = (NAV_end / NAV_start)^(1 / calendar_years) - 1
annualized_vol = sample_std(daily_return) * sqrt(252)
risk_free_daily_t = (1 + yield_pct_t / 100)^(1 / 252) - 1
Sharpe = mean(daily_return - risk_free_daily) / sample_std(excess_daily) * sqrt(252)
tracking_error = sample_std(daily_return - benchmark_return) * sqrt(252)
information_ratio = mean(daily_return - benchmark_return)
                    / sample_std(daily_return - benchmark_return) * sqrt(252)
one_way_turnover = sum(abs(buy_notional) + abs(sell_notional))
                   / (2 * mean(daily_NAV))
```

标准差使用 `n-1` 样本分母。最大回撤使用每日累计净值相对此前历史最高净值的
最小比值；同幅度并列时取最早峰值与最早谷值。月度胜率按完整自然月策略收益
严格大于同月基准收益的月份数除以共同完整月份数。

分母为零、少于两个日收益、所需利率/基准日值未知或样本不足时，对应指标为
`UNKNOWN`。不得只隐藏该指标而仍把整次运行标成完整。

## 10. 偏差控制与黄金验收

实现必须先写 RED fixture，并至少证明：

1. 财报未来版本、未来行业/风险状态和未来股本均不可见；
2. 历史退市证券在当时证券池中保留，当前存续列表不能回填历史；
3. 五年 FCF 不跳过负年，TTM 三段严格同口径；
4. `tests/test_evidence_validate.py` 必须证明受限现金明确为零与受限金额缺失得到
   不同结果；混合金融资产、混合流动负债无法拆分时传播 UNKNOWN；
5. 任一评分分项 UNKNOWN 时权重不重新归一化、`quality_score=None` 且
   `score_coverage<1`；存在证券级 `NEEDS_REVIEW` 时整月不产出官方 Top-N；
   `EVIDENCE=UNKNOWN` 阻断而纯 `INFORMATION=UNKNOWN` 只附注；
6. 诊断报告只能包含状态/原因/质量旗标，schema 测试禁止排名、Top-N、权重、
   订单和净值字段；
7. 行情位置和绝对估值使用同一因子可见集及 hash；
8. 月末收盘信号只能在下一可交易日或以后成交；
9. 20 日参与率任一日不完整时为 `PARTICIPATION_RATE_UNKNOWN`，不跳过缺日；
10. 涨跌停、停牌、T+1、部分成交、五日取消和 100 股手数有边界算例；
11. 费用按历史生效日切换，卖出印花税不施加于买入；
12. 分红、送转、退市未知退出和快照末日 pending 均不产生虚构现金流；
13. 相同输入、配置、代码和规则版本重复运行时，订单、持仓和净值规范逻辑内容
    哈希相同，manifest canonical JSON 相同；
14. 改动 `as_of` 之后的数据不能改变此前任何信号、订单或净值。

订单、持仓和净值输出的“相同”不要求 Parquet 物理文件逐字节相同，因为编码器
元数据、行组布局或时间戳可能变化。每张表必须按冻结主键稳定排序，将 schema
版本、列名、规范类型和值编码成确定性 canonical row stream，再计算 SHA-256
`logical_content_hash`；同一逻辑表的 Parquet 文件可以有不同物理哈希，但逻辑
哈希必须相同。`StrategyRunManifest` 使用现有 canonical JSON 规则序列化；测试
同一输入运行两次，比对三个逻辑哈希和 manifest canonical JSON，不比较 Parquet
文件字节。

策略运行另建不可变 `StrategyRunManifest`，引用基础 `RunManifest.content_hash()`，
并至少记录 `strategy_id=GENERAL_FCF_MONTHLY_TOP20_V1`、
`execution_policy_id=CN_A_OPEN_STRICT_V1`、初始资金、信号区间、全部生产域 snapshot
ID、基准 ID/snapshot、费率表 ID、完整配置哈希、代码/规则版本、完整性摘要以及
订单/持仓/净值输出内容哈希。它不向旧 `RunManifest` 强加新必填字段，避免破坏
v1.0.0–v1.2.0 清单反序列化。

首次真实回测之前不得根据其绩效调整本提案参数。首次完整运行是预先冻结的基线；
任何后续调参都必须新版本、保留原结果，并提供样本内/样本外边界，禁止覆盖。
