## 唯一新增语法

只在 `scripts/parsing/field_binder.py` 的既有显式附注单元格守卫增加：

```text
规范中文整数章节（正 ASCII 整数）正 ASCII 整数
示例：七（79）3
reference_form = CHAPTER_FULLWIDTH_PARENS_ITEM_SUFFIX
syntax_state = OBSERVED_SINGLE_REFERENCE_SYNTAX
note_target_resolved = false
note_semantics_certified = false
```

章节沿用规范中文整数 1—99；括号内项目号和括号后后缀均为无前导零的正 ASCII
整数。必须是一个完整原生词元，保留原始文字和坐标；不去空白、不拼词元、跨行或
跨页，不使用 OCR。只在已识别的非金额附注区匹配，继续服从页内坐标、旋转、原生
词元归属及附注／金额分界守卫。

无符号整数、单横杠、`中文章节、正整数`、`中文章节（正整数）` 四条旧路径保留。
因此拆行的第一片若自身是旧语法完整引用，旧路径仍可能识别该片；这不构成新增
多级后缀识别，不拼接后续碎片，也不认证碎片的目标或财务语义。

拒绝新增形式中的零、前导零、符号、小数、科学计数、未知／非规范章节、ASCII／
半括号、列表、多引用、附注前缀、空白与任意尾文。`七、78（1）`、`七-59（1）`、
`七、79.3` 等不合并支持。没有改金额单元格函数、金额符号／倍率、年度、主体、
主表范围、币种、审计或租赁规则；没有发行人、证券、页码或金额专用分支。
