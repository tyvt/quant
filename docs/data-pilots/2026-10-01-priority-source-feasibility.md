# 三个关键生产域的来源可行性复核（2026-10-01）

**结论：股本、回购和财报均找到可继续验证的候选来源，但没有一个已证明目标区间的完整点时覆盖或获授权的生产使用；三个 Reader 继续 `not_ready`。**
这是来源文档与既有固定样本的桌面审计，未调用需凭证的接口、未采购服务、未发布快照，也不授权真实选股或回测。这里的“历史”特指**目标研究区间内、每个当时 `as_of` 可回放的版本**，不等于今天查询得到一条标有历史日期的记录。

## 1. 历史股本：结构化日值可作为核对线索，不等于生产 `S`

| 候选 | 官方文档已经证明 | 尚不能证明 |
| --- | --- | --- |
| [Tushare `daily_basic`](https://tushare.pro/document/2?doc_id=32) | 含逐交易日 `total_share`、`float_share`，单位均为万股；文档称可按日提取历史，更新窗口为交易日 15:00–17:00。 | 当日值首次公开可用的精确时点、历史值是否被事后修订、所有退市证券/无交易日覆盖、所有股本事件与股类/库存股口径。`float_share` 不能替代 `S`。 |
| [Tushare `stk_premarket`](https://tushare.pro/document/2?doc_id=329) | 含盘前总股本，明确从 **2024-05-01** 开始；文档说明 09:00 和 18:10 更新。 | 更早目标区间，以及某交易日查询值究竟属于当日盘前版本还是后来 18:10 更新版本；也未提供完整历史修订链。即使限定新近区间，仍须固定版本与可用时点。 |
| [Tushare `balancesheet`](https://tushare.pro/document/2?doc_id=36) | 含 `total_share`，但语义是**期末总股本**。 | 期末之后逐日变化和当日 `S`；不可把报告期末值沿时间轴静默前填。 |
| 交易所/巨潮法定 PDF | 既有[一沪一深探针](2026-10-01-historical-shares-pit-probe.md)能核对两次注销桥接和 A/B/D/H 分类。 | IPO 至目标日每个事件、原版/更正/撤回、登记生效日、精确公众可见时点、无事件区间的完整性，以及全市场可持续覆盖。 |

因此**优先建议**：保留 `daily_basic` 作为潜在的逐日对账副证据；把法定公告/登记证据作为股本变动主链候选，先选单股类且无库存股的一只证券，做“上市/期初基数 → 每次变动 → 期末/逐日数”的闭环。若目标区间向 2024 年以前延伸，`stk_premarket` 不能单独补齐。多股类或非零回购专户库存股继续依已批准的[暂行解释](../rule-proposals/2026-10-01-historical-shares-fail-closed.md)使 `S/MV=UNKNOWN`；不因找到 `total_share` 字段而改变。

## 2. 回购逐日：公开进展披露本身不保证逐日明细

[Tushare `repurchase` 官方字段](https://tushare.pro/document/2?doc_id=124)包含 `ann_date`、`end_date`（截止日期）、`proc`、`vol`、`amount` 等，但文档没有逐笔/逐日**执行日期**、稳定**计划 ID**或注销生效日字段。因此不能把 `end_date` 或公告日改写为 `executed_on`。[上交所 2025 年回购指引第三十七条](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/mainipo/c/c_20250516_10779134.shtml)要求首次回购次一交易日、累计比例每增加 1% 后及每月前 3 个交易日披露进展；最低披露内容是累计股数、最高/最低购买价、累计支付金额，**不是每一执行日的金额**。这是对“仅凭所有进展公告即可逐日还原”的明确反证，不排除个别发行人主动披露更细资料。

既有[茅台首日探针](2026-10-01-buyback-first-day-600519.md)只确认 2025-01-02 的 `CNY 299,919,221.00`；至 2025-04-07 的累计观察减去首日后，`CNY 1,648,575,930.53` 仍仅知落于 `(2025-01-02, 2025-04-07]`。区间累计差分有无数种逐日分配，行情量价不能识别发行人专户交易。其余六个区间仍未逐日归属。只有源提供**按证券、计划、执行日、金额**的完整明细，或另经 RULE_SPEC 批准改变区间归属语义，才能讨论生产 `B_buyback`；本审计没有提出后者。

后续来源调查应优先问交易所/发行人或获授权供应商：能否提供回购专户逐日/逐笔成交、计划身份、费用口径、注销/转让流水、原始可用时点、修订链与全计划“零事件”覆盖声明。再次搜索月度公告而未发现逐日行，不可当作“该月没有回购”。

## 3. 财报修订链：有初始/更正标志，不等于完整版本序列

Tushare 的[`income`](https://tushare.pro/document/2?doc_id=33)、[`balancesheet`](https://tushare.pro/document/2?doc_id=36)、[`cashflow`](https://tushare.pro/document/2?doc_id=44)列有报告期、公告日期、报表类型和更新标志等字段；[官方 FAQ](https://tushare.pro/document/1?doc_id=122)说明 `update_flag=0/1` 可区分初始与修正数据，[`fina_audit`](https://tushare.pro/document/2?doc_id=80)另有审计结论字段。这使其值得做**合法授权后的对照样本**，但二值标志不是“原版 → 更正 → 撤回 → 再更正”的有序版本号；文档未承诺同一报告期所有中间版本、精确公布时刻、逐版本审计意见与法定 PDF 一一对应。`report_type=4/5` 等比较期调整记录也不得自动冒充报告期原版/更正版。

用既有[茂化实华修订探针](2026-10-01-financial-revision-000637.md)做首个挑战样本：要求候选源同时返回 2025 年报原版及 2026-08-06 更正版，保留原版经营现金流 `42,986,260.08` 与更正版 `-79,583,416.97` CNY，并能将两次值与各自法定 PDF、报表范围、精确可用时点关联。更正版 PDF 封面仍是原版日期，所以仅凭封面日期或今天的最新行会产生历史泄漏。随后至少验证一条“再次更正/撤回”的真实链，再按报告期和证券全集扩展；单一对照成功仍不证明完整覆盖。

## 许可与供应商接入边界

[Tushare 数据服务协议](https://tushare.pro/document/1?doc_id=405)公开条款将其数据服务许可表述为个人、非商业、仅个人查看使用；API 积分/付费权限**不是**本项目存储原始响应、构造不可变快照、自动化批量研究或对外发布结果的授权证明。使用范围应由项目负责人和供应商另行确认；在此之前不调用付费接口，也不把 Tushare 纳入生产来源。[Wind 企业数据接口](https://www.wind.com.cn/portal/zh/WDS/sapi.html)与[Choice 产品说明](https://choice.eastmoney.com/FileDownLoad/CFTG20221115.pdf)只证明存在机构/量化接口，不证明所需三个数据契约的字段、版本、覆盖或本项目许可；本仓库没有可验收的合同、样本响应或凭证。本节只是技术/许可尽调记录，不是对合同效力的最终法律判断。

## 最小验收包与继续执行顺序

任何拟接入供应商应先提供一份书面许可范围（历史落库、不可变快照、内部回测、衍生结果、留存与共享），以及**按目标日期区间**的原始响应样本和版本说明；不得只给销售截图或当前终值。逐域验收至少要求：

1. **股本**：单股类无库存股样本的期初数、每次事件（数量、股类、生效/登记日、可用时点、原文哈希）及逐日重放；对 `sh.600690`/`sz.000012` 多股类挑战样本必须明确保持 `UNKNOWN`，不得绕过暂行解释。覆盖声明含当时上市、退市、停牌与零变动日期，异常差额硬失败。
2. **回购**：`sh.600519` 已知首日及其余所有执行日逐笔或逐日金额可与累计公告逐段对平；每条有计划 ID、执行日、最早可用时点、注销/转让状态和原文引用。缺任一计划或执行日时整窗 `UNKNOWN`，不得按公告日摊派。
3. **财报**：`sz.000637` 原版/更正版数值与五份法定文件对平；对撤回/再更正、合并/母公司范围、审计意见、缺失版本和同日多公告顺序都有可重放定义。`available_at` 不得早于可核实的公众时点；无精确时点需提交正式规则裁决，不能由适配器猜测。

执行先后：**先索取许可/样本/版本承诺并审核**；若没有获授权的结构化源，则并行推进法定 PDF 的**单发行人、单年度完整公告清单与闭环**，只输出来源可行性和 UNKNOWN，不进入生产 Reader。对股本和财报，PDF 路径仍需证明精确可用时点；对回购，若法定公告只给累计值，继续寻找专户明细，不扩大推断。分红和行业的来源审计可以独立推进；这三项是完整估值/股东回报研究路径的关键阻塞，不是其他域**探针工作**的前置条件。

三个域的 `ready_when`、`RULE_SPEC.md`、历史 `as_of` 和已发布快照均未改变。下一次要作生产状态变更，必须提交目标覆盖区间、真实 PIT fixture、来源许可、撤销/更正处理和不可变快照验收证据。
