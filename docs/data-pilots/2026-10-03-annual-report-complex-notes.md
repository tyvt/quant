# 复杂附注整单元格语法：三家回归

日期：2026-10-03。状态：仅原文提取修复，不是企业硬门验收、真实 PIT 运行或排名。
复核方式：同会话程序回归与三个指定源页自查，没有第三方或第二模型复核。

## 1. 有界实现

只修改 `field_binder.py` 的显式附注单元格守卫，以及 `annual_report_parser.py` 的
逐行附注观察记录。没有证券、发行人、页码或金额专用分支；没有修改币种、表头、
单位、金额分列、母公司边界、跨行科目、租赁标签或审计入口。

在已识别的显式非金额附注栏内，仅接纳**单个完整原生词元**：

- 保留无符号整数 `[0-9]+` 与单个 `-`／`—`／`–` 的旧形式；横杠不代表零。
- 新增 `中文章节、正整数` 与 `中文章节（正整数）`，如 `七、1`、`七（1）`。
- 中文章节限规范中文整数 1—99，不接受“零／〇／百／两／甲”或非规范“九九”。
  新形式的项目号为无前导零的正 ASCII 整数，不接受项目号 0。
- 不删除空白、不拼接词元、跨行或跨页，不接纳列表、半括号、ASCII 括号、逗号、
  `附注七`、`七-1`、带符号金额、小数或科学计数。
- 收紧原守卫：两个独立整数词元 `7`、`1` 不再分别放行，而是
  `NOTE_CELL_NOT_UNAMBIGUOUS_REFERENCE`。不把它们拼成“71”或完整引用。
- 附注必须是当前页的原生词元且坐标在页内及声明附注列内；接触/跨越金额区边界仍
  `NOTE_AMOUNT_BOUNDARY_AMBIGUOUS`，旋转、截断或非原生/越界几何仍 UNKNOWN。

新 `note_column_observation` 保留原 `raw_text` 和 `boxes`，另记 `syntax_state` 与
`reference_form`。成功状态 `OBSERVED_SINGLE_REFERENCE_SYNTAX` **只表示引用语法**，
所有行仍 `note_target_resolved=false`、`note_semantics_certified=false`。无词元记录
`NO_REFERENCE_WORDS`，不认证目标存在或不存在。按龟龟 skill 分离观察与语义/PIT：
语法成功不能认证现金、债务、租赁、审计或企业硬门；没有新增章节锚点解析器。
